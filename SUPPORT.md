# Support

This is the organisation-wide default support guide for Oak National Academy's
repositories. If the repository you are reading has its own `SUPPORT.md`, that
one applies instead.

## Where to ask

| I want to…                                  | Go to                                                                                                     |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Report a bug or request a feature           | The repository's issues, if enabled; otherwise its `README.md` says where feedback goes                    |
| Report an accessibility barrier             | The same route — please mention any assistive technology you were using                                    |
| Report a security vulnerability             | Our [security policy](https://github.com/oaknational/.github/blob/main/SECURITY.md) — **not** a public issue |
| Ask about Oak, our lessons or your account  | [Oak support](https://support.thenational.academy/)                                                        |
| Learn what Oak does                         | [thenational.academy](https://www.thenational.academy/)                                                    |

## What to expect

- Support for our open-source repositories is **best effort**. We read what
  comes in and prioritise it against Oak's roadmap, but we do not commit to a
  response or fix timescale unless a repository's own documentation says
  otherwise.
- Oak works to UK term times, so responses over school holidays may be slower.
- We can clarify what our code and APIs do; we cannot debug your own
  application.

## Contributing

External pull requests are not currently accepted — see our
[contributing guide](https://github.com/oaknational/.github/blob/main/CONTRIBUTING.md)
for what feedback helps most and how to send it.
